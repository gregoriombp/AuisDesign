# create-auis

Alias for [`auis`](https://www.npmjs.com/package/auis), so this works:

```bash
npm create auis@latest my-product
```

Identical to:

```bash
npx auis@latest my-product
```

Options, docs and source live in the [`auis`](https://www.npmjs.com/package/auis)
package and in the [AuisDesign repository](https://github.com/gregoriombp/AuisDesign).

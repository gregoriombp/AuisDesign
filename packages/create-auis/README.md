# create-auis

Alias for [`@auis/cli`](https://www.npmjs.com/package/@auis/cli), so this works:

```bash
npm create auis@latest my-product
```

Identical to:

```bash
npx @auis/cli@latest my-product
```

Options, docs and source live in the [`@auis/cli`](https://www.npmjs.com/package/@auis/cli)
package and in the [AuisDesign repository](https://github.com/gregoriombp/AuisDesign).
